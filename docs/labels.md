# Recommended labels

Core workstream labels:
- `librarian` — ingestion/archival tasks
- `publish` — publication issues

State labels (kanban-ish):
- `state:triage`
- `state:ingested`
- `state:collect`
- `state:ready-to-draft`
- `state:drafted`
- `state:needs-work`
- `state:approved`
- `state:published`

How they are used:
- Actions and/or gh-aw workflows may add/remove these labels to signal stage transitions.
- The revision process happens in the issue conversation, not in pull requests.
